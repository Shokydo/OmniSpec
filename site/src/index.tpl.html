Всё, что нужно от лаунчера сборок

Ни одного нативного окна: диалоги, меню по правой кнопке и подсказки — свои, в стиле лаунчера.

Сборки и категории

Папки-аккордеоны, перетаскивание сборок между ними, дубликаты в «Запущенных». У каждой сборки свои версия, загрузчик, память, Java и иконка.

Modrinth и CurseForge

Две площадки в одном окне: бесконечная лента с догрузкой, вид списком и плиткой, выбор версии под свою сборку и автодокачка обязательных зависимостей.

Лицензия и пиратка

Вход через Microsoft по короткому коду — пароль в лаунчер не попадает. Или ник для офлайн-игры: UUID считается как в самой игре.

Импорт в один клик

.mrpack, .zip-модпак, сборки из Prism, MultiMC и Modrinth App. Импорт видно: спиннер, этап и процент прямо в ленте.

Оформление

16 тем, своя тема с цветами из обоев, форма элементов, обои с историей, трейс за курсором и частицы. Масштаб интерфейса 80–150 %.

Файловый менеджер

Дерево папок, просмотр файлов с номерами строк, архивы zip и rar с зумом картинок, создание папок и перенос файлов мышью.

Быстрый запуск

Проверка файлов, поиск Java и разбор профиля не повторяются каждый раз — повторный запуск сборки идёт заметно быстрее.

Обновляется сам

Кнопка обновления появляется в лаунчере, когда на GitHub выходит новый релиз. Сборки, миры и настройки остаются на месте.

скриншоты

Как это выглядит

Снято с текущей версии — нажми на любой кадр, чтобы открыть его целиком.

аккаунты

Два типа аккаунтов — и честная разница между ними

Профиль в шапке слева, до пяти строк аккаунтов со скроллом в настройках, под каждым — скин и плащ.

  • Лицензия — вход через Microsoft по короткому коду на microsoft.com/link. Токен обновляется сам перед запуском игры.
  • Офлайн — ник 3–16 символов, UUID из него же. Работает без интернета.
  • Скин — wide или slim, второй слой, поворот модели на полные 360° и свои пресеты из загруженных файлов.
  • Плащи — список плащей аккаунта, переключение и «Без плаща» через Mojang API; видно и в ванильном лаунчере.

Что качает сам

Клиент, библиотеки, нативы и ресурсы — с серверов Mojang. Java подходящей версии, если её нет на компьютере: 8 для старых версий, 21 для новых.

Загрузчики

Fabric, Quilt, Forge и NeoForge. Версия игры и версия загрузчика выбираются двумя списками при создании сборки и в «Сменить версию».

Чего пока нет

Смены ника лицензионного аккаунта: ник приходит с серверов Mojang. Импорта чужого manifest.json файлом — модпак CurseForge ставится из каталога, а файлом импортируются .mrpack и .zip.

Скачать портативную
1

Запустить файл

Права администратора не нужны. Windows может показать «неизвестного издателя» — установщик не подписан платным сертификатом: «Подробнее» → «Выполнить в любом случае».

2

Выбрать папку и поставить

По умолчанию предлагается %LOCALAPPDATA%\OmniSpec. Путь запоминается: следующий запуск установщика предложит его же. Переустановка сохраняет сборки и миры.

3

Создать сборку и играть

Готовую сборку можно добавить из Modrinth или импортировать файлом. Java и файлы игры скачиваются при первом запуске.

что лежит в папке установки
OmniSpec.exe        лаунчер
icon.png            иконка для ярлыка
uninstall.exe       деинсталлятор
install-info.txt    версия, путь, режим данных
portable.txt        данные рядом с лаунчером
Удалить можно без установщика: uninstall --yes убирает файлы и ярлыки, --purge — ещё и сборки с настройками.
требования
  • Windows 10 или 11, 64-битная. На «десятке» нужен WebView2 — обычно уже установлен.
  • Интернет для первого запуска сборки: клиент, библиотеки и Java.
  • Место на диске — примерно 1 ГБ на сборку с модами и миром.
  • Linux — бинарник в релизах и сборка из исходников (cargo run -p omnispec-app).
Пароль Microsoft в лаунчер не попадает: вход идёт по device-code, токен живёт час и обновляется сам.
вопросы

Коротко о главном

Нужна ли лицензия Minecraft?

Нет. Офлайн-аккаунт — это просто ник, он работает где угодно без интернета. Лицензия нужна только для скина и плащей через Mojang и для серверов с online-mode.

Лаунчер бесплатный?

Да. Исходники открыты на GitHub, релизы собираются из них автоматически. Никаких подписок и ключей.

Откуда берётся Java?

Лаунчер сам скачивает подходящую версию с серверов Mojang: Java 8 для старых версий игры и Java 21 для новых. Свою Java можно указать в настройках сборки или в разделе «Игра и Java».

Куда сохраняются сборки и миры?

При установке по умолчанию включается портативный режим: данные лежат в OmniSpecData рядом с лаунчером. Если снять галочку — в %APPDATA%\OmniSpec. У сборки может быть своё место установки.

Можно ли импортировать свою сборку?

Да: файл .mrpack, .zip-модпак, сборка из Prism, MultiMC или Modrinth App, а также перетаскивание файла в окно. Экспорт — в .mrpack и .zip.

Обновления сбрасывают настройки?

Нет. Настройки, сборки, миры и время игры остаются; окно первого запуска после обновления не возвращается.

CurseForge поддерживается?

Да, это второй источник рядом с Modrinth: та же сетка, те же панели, фильтры по типу, версии игры и загрузчику, выбор файла и докачка зависимостей. Ключ уже вшит в лаунчер. Модпак ставится в один клик отдельной сборкой: внутри архива читается manifest.json, оттуда берутся версия игры, загрузчик, overrides и список файлов. На главной у ленты есть список «Искать в» — Modrinth или CurseForge.
