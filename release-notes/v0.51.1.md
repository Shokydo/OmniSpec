### Исправления сервера

- Иконки серверов теперь приводятся к PNG 64×64 и записываются атомарно через уникальный временный файл; повреждённая или подменённая symlink-путь не попадает в `server-icon.png`.
- Установка модов и плагинов из серверного каталога повторно проверяет Modrinth project/version/file, тип аддона, Minecraft, загрузчик, URL, имя JAR, границы папок и symlink-защиту на backend.
- После загрузки JAR проверяются обычный файл, размер и SHA-1; при несовпадении файл удаляется.
- В интерфейсе добавлены выбор server icon и встроенный выбор совместимой версии аддона; регрессионный UI-тест покрывает запуск сервера, закреплённую группу, защищённые файлы, бэкап и каталог.

### Проверки

- `cargo test --locked -p omnispec-app -j1`
- `cargo test --locked -p omnispec-core -j1`
- `npm test` в `tools/tests`
- `cargo build --locked --release -p omnispec-app -j1`
