### Пользовательские элементы интерфейса

- В визуальном редакторе можно добавить пользовательский элемент с URL или HTML-кодом, изменить его положение и размер, скрыть, показать, изменить или удалить. Параметры сохраняются в настройках.
- По умолчанию веб-контент и HTML работают во фрейме с ограничениями. Встраивание зависит от правил сайта; некоторые страницы и плееры могут не работать внутри лаунчера.
- Для HTML доступен экспериментальный доверенный режим. После явного подтверждения код получает доступ к интерфейсу и командам лаунчера и может изменять данные и обращаться в сеть. Используйте только проверенный код. После перезапуска приложения доверенный код выключен до повторного подтверждения. Изменение или удаление уже запущенного кода может не остановить его действия до перезапуска.
- Настройки и расположение пользовательских элементов сохраняются при смене готовой компоновки. При общем сбросе конструктора элементы удаляются.

### Ограничения

- Это первая версия функции: поведение отдельных сайтов, авторизации и встраиваемых плееров зависит от WebView и самих сайтов.
- Userscript для изменения сайта Spotify не является embed-кодом плеера. Для вставки используйте код встраивания, предоставленный сервисом.
