### Интерфейс и компоновка

- При первом запуске можно выбрать компоновку OmniSpec, Modrinth или Prism Launcher. В настройках и редакторе доступны те же компоновки с изображениями; это оформление OmniSpec, вдохновлённое указанными лаунчерами.
- В визуальном редакторе можно объединить список сборок с рабочей областью: один клик выбирает сборку, двойной клик или кнопка открывают её страницы. Кнопка запуска остаётся в верхней панели.
- Кнопки «назад» и «вперёд» перемещаются по истории вкладок текущей сборки. Панель вкладок может располагаться горизонтально или вертикально слева.
- Для подложек элементов добавлено индивидуальное закругление, для установленных сборок — размер карточек, для каталога сборок — шесть размеров. Карточки модпаков в сетке упрощены.
- Темы и CSS-заготовки в настройках интерфейса теперь включаются переключателями; их порядок по-прежнему можно менять.

### Серверы

- Каталог «Загрузить с Modrinth» автоматически показывает проекты, подходящие версии Minecraft и ядру сервера, и позволяет искать моды или плагины.
- Серверные панели и элементы интерфейса лучше учитывают выбранный стиль скруглений.

### Известные ограничения

- Пресеты Prism и Modrinth передают особенности компоновки, но не являются точными копиями этих приложений. Полная независимость всех вложенных элементов редактора ещё не реализована.
- JavaScript-темы и внешние CSS @import пока не поддерживаются.
- Проверка конфигов не устраняет блокировки, появившиеся после запуска игры; причина ошибок записи конфигурации ATM6/ATM9 не подтверждена. Автозагрузка Java может выбрать устаревшую Java 8; полная проверка зависимостей модов перед запуском пока не реализована.
