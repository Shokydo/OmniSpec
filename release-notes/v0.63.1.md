### Визуальный редактор

- Левая панель элементов и правая панель свойств прокручиваются независимо, холст остаётся на месте.
- Для пользовательских элементов доступно редактирование HTML, CSS, JavaScript и URL в отдельном окне. Доверенный код требует подтверждения.
- Исправлена привязка к сетке при перемещении и изменении размера элементов. Уже существующие раскладки не изменяются автоматически; стандартные раскладки ещё не выровнены по сетке.

### Пользовательские элементы

- Ссылки на отдельные ролики YouTube открываются через встроенный плеер. Доступность зависит от ограничений YouTube и WebView: отдельные ролики могут быть недоступны, возможна ошибка 153. Другие сайты могут запрещать встраивание.
