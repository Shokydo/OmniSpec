### Экранные эффекты

- Кнопки эффектов переносятся на несколько рядов, чтобы подписи оставались видимыми.
- Добавлены всплывающие и лопающиеся пузырьки. Для всех экранных эффектов можно выбрать направление: вверх, вниз, влево или вправо; настройка сохраняется после перезапуска.

### Описание обновлений

- В окне обновления лаунчера отображается раздел «Что изменилось» из релиза GitHub, включая промежуточные версии, когда они доступны.
- В анонсы Discord передаётся список изменений релиза. Длинный текст разбивается на несколько сообщений; при ошибке получения описания пустой анонс не отправляется.

### Ограничения

- На уже установленной версии 0.57.1 окно обновления использует прежний код; новый способ отображения списка изменений заработает после установки 0.57.2.
- Canvas-частицы и след курсора стилизуются через CSS целиком, а не по отдельности. Внешние CSS `@import` и JavaScript-темы не поддерживаются; полная независимость вложенных элементов редактора ещё не реализована.
