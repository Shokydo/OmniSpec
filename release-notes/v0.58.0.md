### Пресеты памяти для сборок

- Под ползунком выделения ОЗУ добавлены быстрые варианты **4, 8, 12 и 16 ГБ** — при создании сборки, в настройках существующей сборки и в общих настройках.
- Ползунок по-прежнему позволяет выбрать другое значение; активный пресет выделяется автоматически. Значения выше доступного предела отключены.
- Подсказка напоминает оставить память операционной системе и другим приложениям. Прежние сохранённые значения не меняются без действий пользователя.

### Ограничения

- При неизвестном объёме ОЗУ предел ползунка приблизительный: проверьте объём памяти компьютера вручную и оставьте запас для системы.
- Canvas-частицы и след курсора стилизуются через CSS целиком, а не по отдельности. Внешние CSS `@import` и JavaScript-темы пока не поддерживаются.
