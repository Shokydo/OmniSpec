### Автозапуск пользовательских JS-скриптов

- В разделе «Настройки → Интерфейс → Пользовательские JS-скрипты» появилась отдельная настройка автозапуска для каждого импортированного файла.
- Доверенный код запускается автоматически только после отдельного подтверждения. Разрешение привязано к конкретному коду, режиму и устройству: при изменении кода его нужно подтвердить снова. Доверяйте только проверенным скриптам: они получают доступ к лаунчеру, данным и сети.
- Выключение доверенного скрипта не всегда отменяет уже выполненные действия, таймеры и обработчики — для полной остановки может понадобиться перезапуск. Изолированные скрипты не изменяют интерфейс лаунчера.

### Аварийное восстановление и трей

- По ПКМ на значке OmniSpec доступны настройки, профиль, восстановление интерфейса и выход. Значок доступен независимо от настройки сворачивания в трей.
- **Ctrl + Shift + Backspace** в активном окне или пункт «Восстановить интерфейс» в трее включает аварийный режим: пользовательские CSS и раскладка временно отключаются, автозапуск скриптов выключается. Темы и настройки не удаляются; после исправления проблемной темы оформление можно вернуть в настройках интерфейса.

### Папка тем и пользовательский CSS

- CSS-файлы из папки `themes` отображаются в списке тем; при возвращении в окно или нажатии «Обновить из папки» список и изменения файлов перечитываются. Новые темы выключены до включения пользователем. Файлы, импортированные вручную, остаются в настройках.
- Исправлен приоритет переменных цвета пользовательского CSS: значения в `:root` больше не перекрываются настройками цвета лаунчера.
- Кнопка папки скриптов открывает её в проводнике; JS-файлы по-прежнему необходимо импортировать вручную.
