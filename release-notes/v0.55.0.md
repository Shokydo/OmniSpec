### Интерфейс и темы

- В разделе «Интерфейс» доступны готовые компоновки и переключаемые CSS-заготовки. Собственные CSS-файлы можно импортировать кнопкой или перетащить мышью; порядок применения меняется перетаскиванием или кнопками.
- Визуальный редактор открывается отдельной кнопкой. Добавлены строка пути сборки, список и компактная сетка сборок, отдельные настройки прозрачности подложки и размытия.

### Java и проверка конфигов

- Автоматический подбор Java учитывает нужную версию профиля: несовместимый общий путь не мешает поиску при включённой автозагрузке. Явный путь конкретной сборки проверяется отдельно.
- При загрузке Java с серверов Mojang проверяются размер и контрольная сумма файлов. Добавлен компонент java-runtime-epsilon.
- Перед запуском проводится неразрушающая проверка записи в папку конфигурации; на Windows — проверка доступности существующих конфигов. При обнаружении проблем показывается предупреждение.

### Известные ограничения

- Проверка не устраняет блокировки конфигов и не обнаруживает блокировку, появившуюся после старта игры. Причина сбоев ATM6 и ATM9 не подтверждена; этот релиз предназначен для диагностики, а не гарантированного исправления.
- Автозагрузка использует рантаймы Mojang и может выбрать старую Java 8u51; загрузка актуальной Temurin 8 ещё не реализована.
- JavaScript-темы, внешние CSS @import, полная независимость вложенных элементов и полная проверка зависимостей модов до запуска ещё не реализованы.
