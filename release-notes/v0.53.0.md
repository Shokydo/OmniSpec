### Редактор CSS и интерфейса

- Во вкладке CSS загружается полный исходный `styles.css`: изменения применяются сразу и сохраняются между запусками. Существующие пользовательские переопределения остаются совместимыми.
- Добавлены поиск, Tab для отступов, Ctrl+S, импорт и экспорт `.css`, а также восстановление стандартного стиля сочетанием Ctrl+Shift+Backspace.
- Холст показывает копии содержимого панелей; во время перетаскивания блок следует за указателем.

### Список сборок и Java

- Закреплённая категория запущенных сборок больше не сжимается при открытых категориях; при большом количестве запусков список внутри неё прокручивается.
- Выбор Java использует точную мажорную версию профиля и проверяет указанный или скачанный рантайм. Если подходящей Java нет, лаунчер предлагает установить её или настроить путь.

### Известные ограничения

- Визуальный холст пока показывает копии элементов: свободное перемещение работающих окон и настоящие раскладки Prism/Modrinth ещё не реализованы.
- Полная диагностика зависимостей и конфликтов модов до запуска ещё не реализована.
